# Лабораторная 4

## Отрабатываемый материал

xUnit, Moq, FluentAssertions, TestContainers, WebApplicationFactory

## Задание

Покрыть реализованный сервис модульными и интеграционными тестами.

### Модульные тесты

- Необходимо написать модульные тесты на сервисы бизнес логики
- Необходимо использовать моки для инфраструктуры
- Модульные тесты должны проверять как позитивные, так и негативные сценарии
  - Негативные сценарии должны включать как сценарии бизнес логики (некорректные операции), так и проверку
    инфраструктурных инвариантов (некорректные входные данные, не существующие сущности)

### Интеграционные тесты

- Необходимо написать интеграционные тесты на все методы репозиториев
  - Особенно на методы работающие с сериализацией (для них покрыть все возможные типы данных)
- Необходимо написать интеграционные тесты на основные эндпоинты
  - Создание счёта
  - Пополнение/снятие с счёта
  - Создание инвойса
  - Оплата инвойса
- Интеграционные тесты должны покрывать позитивные сценарии и основные негативные сценарии бизнес логики
  - Интеграционные тесты не должны покрывать сценарии проверки инфраструктурных инвариантов
- Интеграционные тесты должны использовать реалистичное окружение
  - Должен быть использован WebApplicationFactory, созданный из реального проекта (можно
    использовать [Itmo.Dev.Platform.Testing](https://www.nuget.org/packages/Itmo.Dev.Platform.Testing/) и
    PlatformWebApplicationBuilder)
  - Должна быть использована настоящая БД (TestContainers)
- Интеграционные тесты не должны использовать моки
  - Все сущности, используемые в тестах должны быть в действительности созданы в БД
  - Допускается добавление сущностей напрямую через репозитории в Arrange секции тестов, а не через API
